# Beholder 2 Mod Editor — редактор модификаций

[English](README.md) · **[Скачать аддон для Windows](https://github.com/BurimBasic/BEHOLDER-2-MODEDITOR/releases/download/v0.2.0-alpha.1/Beholder2-ModEditor-v0.2.0-alpha.1-Windows.zip)** · **[Купить и установить игру в Steam](https://store.steampowered.com/app/761620/Beholder_2/)**

Экспериментальный внутриигровой редактор сцен и мод управления первым этажом Министерства. Это рабочая альфа, а не готовая замена Unity Editor. Коммерческая игра в архив не входит.

## Простая установка

1. Скачайте **Windows ZIP** по ссылке выше и распакуйте его **вне папки оригинальной игры**.
2. Запустите **Install.cmd**, выберите папку с оригинальным `Beholder2.exe`. Установщик создаст отдельную копию игры в `prototype`, установит мод и построит каталог ресурсов. Потребуется место ещё для одной копии игры.
3. Запустите **LaunchMod.exe**. Для сценария управления начните новую игру. Редактор открывается **F8** или кнопкой **Mod Editor** в главном меню.

Сохранения аддона отдельные: `fresh-profile`. Проекты редактора: `prototype/ModEditorProjects`. Оригинальная игра не изменяется. Для обновления закройте аддон, распакуйте новый выпуск поверх старого и снова выполните Install.cmd; сохранения и проекты сохраните. Для удаления сначала скопируйте нужные проекты и сохранения, затем удалите папку аддона.

## Управление редактором

- **«Сцена: выбрать»** слева сверху — открыть сцену из меню. Кабинет: `BossRoom`.
- **ПКМ + WASD** — полёт камеры; **Q/E** — вниз/вверх; **Shift** — ускорение.
- **W/E/R** без ПКМ — перемещение, вращение и масштаб объекта. Справа точные XYZ. **F** — приблизить объект, **Esc** — отменить перенос.
- **«Библиотека всех файлов»** — поиск ресурсов по всей установленной игре, по имени, типу и файлу. **«Найти в сцене»** — перейти к сценовому объекту.
- **«Предметы сцены» → «Поставить»** — добавить декорацию. Её можно перемещать, удалять, сохранять; доступны отмена и повтор.
- **«Сохранить»** — записать проект для следующего запуска. **IndexAssets.cmd** перестраивает каталог файлов.

Полный каталог не означает, что уже можно создать любой ресурс как игровой объект. Размещаются статические модели текущей сцены; перенос из других сцен и автоматическое копирование логики NPC, дверей и терминалов пока не реализованы. Редактор диалогов, квестов и событий — следующие этапы.

## Совместимость

Проверена Windows-версия на Unity 2018.4.4f1/Mono. Установщик сверяет хеш оригинальной сборки и отказывается менять неподдерживаемую версию. Для установки нужен .NET Framework 4.x; для сборки исходников — .NET SDK. Начинайте с новой игры и не используйте основное сохранение для экспериментов.

В моде также есть прототип кабинета начальника, досье/отчётов, почты по шаблонам, очереди с охраной, приёма сотрудников и обращений.
