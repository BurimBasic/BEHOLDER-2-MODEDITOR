# Changelog

## 0.2.0-alpha.1

- First public source and Windows addon release.
- In-game hierarchy, scene preview, inspector and W/E/R transform gizmos.
- Right-mouse WASD/QE scene-camera navigation.
- File-wide local asset metadata catalog; scene-object lookup.
- Static prop placement, deletion, project persistence and undo/redo.
- Native action label/cost/time editing.
- First-floor management prototype, reception and petition processing.
- Stop seated-avatar alignment during editor mode so Evan can be moved with XYZ.
- Hide the Ferguson pose-sampling copy.
- Isolated installation with original-game hash validation and separate saves.

Known limitations are listed in README.md; universal asset spawning and full dialogue/event authoring are not implemented in this alpha.
